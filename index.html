Authentication

No API key needed. Every endpoint is open — just call it directly with your query parameters.

Rate limiting

Each visitor gets their own quota, tracked by IP address. Default is 30 requests per 15 minutes. If you go over, you'll get a 429 response — wait for the window to reset and try again.

Endpoints

Both return JSON, except the stream endpoint, which returns raw audio.

GET /api/scdlv2

Search a song

Find a track by name and get back its title, artist, artwork, duration, and a link to stream it.

Query parameters
NameTypeRequiredDescription
querystringrequiredThe song name to search for.
Example request
# cURL
curl "https://helixsong.vercel.app/api/scdlv2?query=Happy%20Nation"
Example response · 200 OK
{
  "status": true,
  "result": {
    "title": "Happy Nation",
    "artist": "Ace of Base",
    "duration": 210000,
    "thumbnail": "https://cdn.example.com/artwork.jpg",
    "download_url": "https://helixsong.vercel.app/api/stream?track=..."
  },
  "credit": {
    "name": "HELIX TANVIR",
    "contact": "https://www.facebook.com/mdtanvir.albert/"
  }
}
Possible errors

400 – missing query · 404 – no match found · 429 – rate limit exceeded · 500 – upstream error

GET /api/stream

Stream the audio

Returns the actual audio bytes for a track. This is what result.download_url already points to — you won't usually build this URL by hand.

Query parameters
NameTypeRequiredDescription
trackstringrequiredThe track reference returned inside a search result's download_url.
Response headers
Content-Type: audio/mpeg
# No Content-Disposition header — plays inline, doesn't force a download
Possible errors

400 – missing or invalid track reference · 429 – rate limit exceeded · 500 – upstream error

Error codes

Every error response follows the same shape: { "status": false, "message": "..." }

CodeNameMeaning
400Bad RequestA required parameter is missing or invalid.
404Not FoundNo matching, playable track was found for that query.
429Too Many RequestsYou've hit the rate limit for your IP. Wait for the window to reset.
500Internal Server ErrorSomething failed upstream while searching or streaming.
